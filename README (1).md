## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/data-visualization-suite.git
cd data-visualization-suite
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run all charts at once
```bash
python run_all.py
```
All chart images will be saved to the `output/` folder.

### 4. Run a single chart
```bash
python charts/chart06_heatmap.py
```
